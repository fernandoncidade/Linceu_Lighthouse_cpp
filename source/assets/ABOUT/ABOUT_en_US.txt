Description: Local File Activity Intelligence, History & Audit Platform
"Know exactly what happened to your files — locally, visually, deterministically."

Linceu Lighthouse is a native C++17 desktop application with Qt6 designed to provide total visibility, structured history, and deterministic auditing over the Windows file system. Rather than operating as a simple ephemeral monitor or a restrictive security tool, Linceu Lighthouse integrates three essential layers into a single fluid and modern experience:

1. Continuous Activity Monitoring: Real-time tracking of events in the file system (creation, modification, deletion, renaming, moving, and initial scan), with precise semantic correlation of complex events (such as real identification of RENAMED and MOVED without false deletion records).
2. Searchable History and File Intelligence without AI: Automatic construction of a local historical database in SQLite, enriched with over 30 categories of metadata before and after each change, accompanied by 17 types of native graphical visualizations and detailed statistics.
3. Security, Audit, and Evidence Generation: Cryptographic baseline, deterministic risk score calculation, local rules engine, quarantine, restoration, and export of forensic evidence packages and executive reports (XLSX, CSV, JSON, XML, TXT, and SQLite).

Absolute Commitment to Privacy (Local-First):
Your data never leaves your computer. Linceu Lighthouse operates 100% offline, without cloud dependency, without telemetry collection, without account creation, and without artificial intelligence or language models (LLM/RAG). All analytical intelligence stems from deterministic statistical and computational algorithms executed directly on your processor.


The 5 Operating Modes of Linceu Lighthouse

* Monitoring Mode: Real-time visual tracking of work folders, source code, or critical directories with instant chromatic signaling.
* History Mode (File History / What Changed?): Temporal query to answer "What happened to my file?", tracking its genealogical tree of edits, renames, and moves.
* Intelligence & Analytics Mode: Understanding operational patterns, peak activity times, most modified file types, and temporal heatmaps.
* Security & Integrity Mode: Deterministic anomaly detection, cryptographic hash auditing, integrity preservation, and session management.
* Evidence Mode: Generation of consolidated reports and exported databases for compliance purposes, internal auditing, or incident resolution.


Key Use Cases and Target Audiences

- Software Developers and Engineers: Track exactly which files were created, modified, or deleted by compilation processes, automation scripts, IDEs, or version control tools.
- System Administrators and Technical Support: Diagnose missing files, improper changes in shared folders, and trace root causes of failures in the local environment.
- Professionals with Sensitive Data (Legal, Healthcare, Finance, Engineering): Audit confidential file movements without exposing data to external servers or third-party services.
- Content Creators (Designers, Video Editors, Photographers): Maintain strict control over large volumes of media, heavy projects, and rendering pipelines.
- General Users: Preventive control against accidental file loss in download folders, documents, or backup drives.


How Linceu Lighthouse Works

1. Establishment of the Baseline (Snapshot): Upon selecting a folder, the scanner performs a recursive scan creating an initial snapshot with detailed metadata for each item.
2. Asynchronous Monitoring with Native APIs: The ReadDirectoryChangesW engine captures Windows notifications in the background, handling spikes through thread-safe buffers and parallel workers.
3. Normalization and Correlation of Events: Raw events are correlated to distinguish renames and moves from standalone creations/deletions.
4. Metadata Enrichment: Specific attributes are extracted (real MIME, dimensions, duration, authors, bitrates, signatures, and hashes).
5. Batch Persistence in SQLite: Asynchronous writing ensures continuous persistence without freezing the graphical interface.
6. Presentation, Filtering, and Visualization: The Qt6 interface enables instant search, combined filtering, generation of 17 native diagrams, and complete export.


Analysis Tools and Available Resources

- Quick and Advanced Filters: Filter by event type, date range, text, file extension, or direct selection in the table.
- Native Visual Statistics (17 Charts): Pie, Bar, Timeline, Treemap, Histogram, Pareto Curve, Line, Boxplot, Radar, Temporal Heatmap, Scatter, Sankey Diagrams, Dotplot, and Directory Tree visualization.
- Complete Evidence Export: Export reports to Excel (.xlsx), CSV (.csv), Text (.txt), JSON (.json), XML (.xml), and SQLite Database (.db).
- Full Internationalization: Interface and manuals available natively in Portuguese (pt_BR), English (en_US), Spanish (es_ES), French (fr_FR), Italian (it_IT), and German (de_DE).

QUICK USE MANUAL:

1. Run the application from the shortcut or executable.
2. Click "Select Directory" and choose the folder you wish to audit.
3. Click "Start/Stop" to perform the initial scan and start continuous observation.
4. Use the sidebar buttons and top menus to filter events, view statistical charts, and manage security.
5. Double-click any item in the table to open it with the default application or choose a custom tool.
6. Access "Save As" to export evidence and reports in the format of your choice.

DETAILED USER MANUAL:

System Requirements:
- Operating System: Windows 10 (64-bit) or higher (Windows 11).
- Read permission on monitored directories.
- Write permission to %LOCALAPPDATA%\LinceuLighthouse.

Setup and Operation:
1. Monitored Directory: The selected path is monitored recursively (including all subfolders).
2. Data and Metadata Table:
   - Operation: Visually indicated with customizable color coding.
   - Name and Paths: Previous path and current path clearly indicated for move/rename events.
   - Dates: Creation, modification, and last access dates preserved even for folders and subfolders.
   - Type and MIME: Accurate content classification based on real file signatures.
3. Advanced Filters:
   - Access Settings → Filters → Advanced Filters to combine multiple criteria with visual calendar support.
4. Statistics and Charts:
   - Access via the File → Statistics menu to generate any of the 17 available graphical analyses and save them in high resolution.
5. Export and Archiving:
   - Filtered data or the entire database can be exported at any time in industry-standard formats.
6. Language:
   - Change the language in Options → Language with instant dynamic reloading.
