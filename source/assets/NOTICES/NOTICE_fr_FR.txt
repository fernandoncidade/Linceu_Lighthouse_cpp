Avis de Dépendances Tiers et de Licences

Cet avis s'applique à l'édition C++/Qt6 du projet Linceu Lighthouse.
Il remplace les avis hérités de l'ancienne implémentation en Python/PySide6. La base actuelle ne dépend plus, pour l'exécution principale de l'application, de la chaîne de bibliothèques Python précédemment listée.

- Qt::Core
- Qt::Gui
- Qt::Widgets
- Qt::Sql
- Qt::Xml

- Qt::OpenGLWidgets

2. SQLite / pilote QSQLite
Usage dans le projet :
- persistance locale du monitoring, requêtes et exportation vers `.db` via `QSqlDatabase`, `QSqlQuery` et le pilote `QSQLITE`.

Licences :
- SQLite est un logiciel du domaine public ;
- lorsque le plugin/pilote QSQLite est redistribué dans une installation Qt, la couche Qt du plugin suit les conditions de la distribution Qt utilisée, tandis que le noyau SQLite reste dans le domaine public.

Référence officielle SQLite :
- https://www.sqlite.org/copyright.html

3. API natives de Windows
Usage dans le projet :
- surveillance des fichiers et répertoires ;
- lecture de version et de signature numérique des exécutables ;
- intégration shell et ressources spécifiques à la plateforme.

Composants identifiés dans le build/code :
- `wintrust`
- `version`
- `crypt32`
- API Windows/Windows SDK telles que `ReadDirectoryChangesW`, `CreateFileW`, `WinVerifyTrust`, `GetFileVersionInfoW` et `VerQueryValueW`.

Observation de licence :
- ces composants font partie du système d'exploitation Windows et/ou du SDK Microsoft ;
- ils ne sont pas redistribués par ce projet comme bibliothèques open source tierces indépendantes.

4. Outils de build et de maintenance
- la compilation des traductions peut utiliser `lrelease`, distribué dans l'écosystème Qt ;
- cet outil fait partie du flux de build/maintenance et ne constitue pas, à lui seul, une dépendance de runtime de l'application finale.

Observation finale
- les anciens avis concernant PySide6, pandas, NumPy, matplotlib, openpyxl, pyOpenSSL, pywin32 et les bibliothèques Python associées ne décrivent plus l'implémentation actuelle en C++/Qt6 ;
- les textes de licence inclus dans `source/assets/LICENSES` doivent être interprétés conjointement avec les composants effectivement redistribués dans le paquet final de l'application.
