Aviso de Dependências de Terceiros e Licenças

Este aviso aplica-se à edição C++/Qt6 do projeto Linceu Lighthouse.
Ele substitui os avisos herdados da implementação anterior em Python/PySide6. A base atual não depende mais, para a execução principal da aplicação, da cadeia de bibliotecas Python anteriormente listada.

Dependências efetivamente identificadas na base atual

1. Qt 6
Módulos usados pelo projeto:
- Qt::Core
- Qt::Gui
- Qt::Widgets
- Qt::Sql
- Qt::Xml
- Qt::Concurrent
- Qt::OpenGL
- Qt::OpenGLWidgets
- Qt::Quick
- Qt::Qml

Finalidade no projeto:
- interface gráfica, internacionalização, concorrência, renderização de gráficos/diagramas, XML e acesso a banco de dados.

- este projeto foi preparado para operar com bibliotecas Qt fornecidas como binários separados e substituíveis no cenário padrão de distribuição com bibliotecas compartilhadas.

2. SQLite / driver QSQLite
Uso no projeto:
- persistência local do monitoramento, consultas e exportação para `.db` via `QSqlDatabase`, `QSqlQuery` e driver `QSQLITE`.

Licenciamento:
- SQLite é software em domínio público;
- quando o plugin/driver QSQLite é redistribuído como parte da instalação Qt, a camada Qt do plugin segue as condições da distribuição Qt utilizada, enquanto o núcleo SQLite permanece em domínio público.

Referência oficial do SQLite:
- https://www.sqlite.org/copyright.html

3. APIs nativas do Windows
Uso no projeto:
- monitoramento de diretórios e arquivos;
- leitura de versão e assinatura digital de executáveis;
- integração de shell e recursos específicos da plataforma.

Componentes identificados no build/código:
- `wintrust`
- `version`
- `crypt32`
- APIs do Windows/Windows SDK como `ReadDirectoryChangesW`, `CreateFileW`, `WinVerifyTrust`, `GetFileVersionInfoW` e `VerQueryValueW`.

Observação de licenciamento:
- esses componentes fazem parte do sistema operacional Windows e/ou do SDK da Microsoft;
- eles não são redistribuídos por este projeto como bibliotecas open source independentes de terceiros.

4. Ferramentas de build e manutenção
- a compilação de traduções pode utilizar `lrelease`, distribuído no ecossistema Qt;
- essa ferramenta é de build/manutenção e não constitui, por si só, dependência de runtime da aplicação final.

Observação final
- os avisos antigos sobre PySide6, pandas, NumPy, matplotlib, openpyxl, pyOpenSSL, pywin32 e bibliotecas Python correlatas não descrevem mais a implementação atual em C++/Qt6;
- os textos de licença incluídos em `source/assets/LICENSES` devem ser interpretados em conjunto com os componentes efetivamente redistribuídos no pacote final do aplicativo.
