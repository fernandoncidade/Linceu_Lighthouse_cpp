# Manual do Usuário — Linceu Lighthouse

Bem-vindo ao Linceu Lighthouse. Este manual fornece instruções para operar o aplicativo — voltado ao usuário final — sem detalhes técnicos.

## Início Rápido
- **Abrir o aplicativo:** Execute o programa pelo atalho ou executável disponível.
- **Selecionar pasta para monitorar:** Use o botão ou a opção "Adicionar Diretório" para escolher a pasta que deseja observar.
- **Iniciar varredura:** Pressione "Iniciar" ou "Scan" para escanear a pasta selecionada; uma barra de progresso mostrará o andamento.

## Varredura e Monitoramento
- **Scan único:** Executa uma verificação imediata da pasta selecionada.
- **Monitoramento contínuo:** Ative o modo de monitoramento para que novas alterações (criação, modificação, movimentação, exclusão) apareçam automaticamente.

## Visualização e Navegação
- **Tabela de itens:** Arquivos e pastas são exibidos em uma tabela com colunas como nome, tipo, tamanho e data.
- **Ordenar e redimensionar:** Clique no cabeçalho das colunas para ordenar; ajuste larguras arrastando as bordas.
- **Detalhes do item:** Selecione uma linha para ver informações e metadados no painel lateral.
- **Pesquisa:** Use a caixa de busca para localizar itens pelo nome rapidamente.
- **Filtros:** Aplique filtros por tipo, tamanho, data ou categorias para reduzir resultados.

## Metadados e Informações
- **Ver metadados:** Selecionando um arquivo você vê atributos como autor, dimensões, duração e proteção, quando disponíveis.
- **Atualizar metadados:** Utilize a opção "Atualizar" para reextrair informações do item selecionado.

## Ações sobre Arquivos
- **Abrir:** Dê duplo clique ou use o botão "Abrir" para abrir o arquivo com o programa padrão do sistema.
- **Copiar / Cortar / Colar:** Selecione itens e use os comandos correspondentes para mover ou copiar entre pastas.
- **Renomear / Excluir / Criar:** Use o menu de contexto (clique direito) para renomear, excluir ou criar arquivos/pastas.
- **Restaurar exclusões temporárias:** Quando disponível, utilize a função de restauração para recuperar itens removidos recentemente.

## Estado da Tabela e Preferências
- **Salvar estado da tabela:** Salve a configuração atual de colunas (ordem, largura, visibilidade) para reutilizar.
- **Restaurar estado:** Carregue um estado salvo para voltar à mesma disposição de colunas e filtros.

## Configurações e Idiomas
- **Preferências:** Acesse as configurações para ajustar comportamento de scan, notificações e opções gerais.
- **Idioma:** Altere o idioma da interface nas opções de idioma disponíveis (Português, Inglês, Espanhol, Italiano, Francês, Alemão).
- **Atualizações:** Habilite atualizações automáticas ou verifique manualmente se houver opção para isso.

## Relatórios e Estatísticas
- **Gerar estatísticas:** Use a função de estatísticas para visualizar gráficos sobre tipos de arquivos, uso de disco e eventos.
- **Exportar:** Exporte gráficos ou relatórios para arquivos (imagem ou dados) quando precisar compartilhar ou arquivar.

## Mensagens, Notificações e Progresso
- **Painel de mensagens:** Consulte mensagens e avisos do aplicativo para entender ações recentes.
- **Barra de progresso:** Acompanhe operações longas (scan, extração em lote) pela barra de progresso; aguarde a conclusão.

## Processamento em Lote
- **Extrair metadados em lote:** Selecione múltiplos itens e escolha a opção de processamento em lote para extrair metadados de todos.
- **Pausar/Cancelar:** Você pode pausar ou cancelar operações em lote pelos controles exibidos durante o processo.

## Atalhos e Usabilidade
- **Menu de contexto:** Clique com o botão direito para acessar ações rápidas (abrir, excluir, copiar caminho, etc.).
- **Teclas de atalho:** Utilize atalhos para ações comuns; verifique a lista de atalhos nas Preferências.
- **Dicas:** Passe o mouse sobre botões para ver dicas de uso.

## Segurança e Proteção
- **Ver proteção de arquivos:** Confira se um arquivo está protegido antes de tentar editá-lo.
- **Confirmações:** O aplicativo pede confirmação antes de executar exclusões em massa; leia antes de confirmar.

## Ajuda e Suporte
- **Manual completo:** Consulte a opção "Ajuda" no aplicativo para rever este manual e outras instruções.
- **Mensagens de erro:** Em caso de erro, siga as instruções exibidas; muitas vezes basta tentar novamente ou verificar permissões da pasta.
- **Contato:** Veja a seção "Sobre" ou "Ajuda" para informações de contato e licenciamento.

## Dicas Finais
- Teste operações em uma pasta pequena antes de processar grandes volumes.
- Salve estados e preferências para acelerar sessões futuras.
- Use filtros e pesquisa para localizar arquivos sem percorrer toda a lista.

## Visão Geral
Linceu Lighthouse ajuda a inspecionar, monitorar e analisar arquivos e pastas em uma ou mais localizações do seu computador. Ele apresenta uma lista centralizada com informações detalhadas para cada item e ferramentas para filtrar, gerar estatísticas e executar ações comuns de gerenciamento de arquivos.

## Tela Principal — Elementos Principais
- **Barra de ferramentas:** Acesso rápido a ações como Adicionar Diretório, Iniciar Scan, Parar, Atualizar e Abrir Preferências.
- **Área de seleção de diretórios:** Botões ou menu para adicionar, remover ou alternar pastas monitoradas.
- **Tabela de itens:** Lista central com colunas que exibem Nome, Tipo, Tamanho, Data, Evento e outras informações.
- **Painel lateral de detalhes:** Mostra metadados e informações estendidas para o item selecionado.
- **Painel de mensagens/progresso:** Exibe notificações, barra de progresso e mensagens de operação.
- **Seção de estatísticas/graficos:** Área para visualizar relatórios e gráficos gerados a partir dos dados coletados.

## Como Começar (Passo a Passo)
1. Abra o aplicativo pelo atalho ou executável.
2. Clique em **Adicionar Diretório** e selecione a pasta que deseja monitorar.
3. Clique em **Iniciar** ou **Scan** para executar uma varredura inicial.
4. Aguarde a conclusão; os itens aparecerão na tabela com os dados extraídos.
5. Ative **Monitoramento contínuo** se quiser que alterações sejam detectadas automaticamente.

## Modos de Operação
- **Scan Único:** Faz uma verificação imediata da(s) pasta(s) selecionada(s).
- **Monitoramento Contínuo:** Mantém a aplicação observando alterações em tempo real e atualiza a tabela automaticamente.
- **Processamento em Lote:** Permite extrair metadados ou gerar relatórios para múltiplos arquivos ao mesmo tempo.

## Entendendo a Tabela de Itens
- **Nome:** Nome do arquivo ou pasta; clique duas vezes para abrir.
- **Tipo:** Tipo detectado (ex.: imagem, vídeo, documento, pasta).
- **Tamanho:** Mostra o tamanho em unidade legível; pode ser convertido entre KB/MB/GB.
- **Data:** Data da última modificação ou evento registrado.
- **Evento:** Indica ações detectadas (criado, modificado, movido, excluído).

Observações: você pode ordenar por qualquer coluna e ajustar a largura clicando e arrastando o cabeçalho.

## Painel de Detalhes / Metadados
Ao selecionar um item, o painel lateral exibe campos relevantes quando disponíveis, por exemplo:
- **Caminho completo** — local do arquivo no disco.
- **Autor / Criador** — quando extraído de metadados.
- **Dimensões** — para imagens (largura x altura).
- **Duração** — para arquivos de áudio/vídeo.
- **Taxa de bits** — para mídias, se disponível.
- **Proteção / permissões** — indica se o arquivo está protegido contra alterações.
- **Outros** — tags, descrição, número de linhas (para arquivos de texto), etc.

## Ações Disponíveis
- **Abrir:** Abra com o aplicativo padrão do sistema (duplo clique ou botão Abrir).
- **Copiar / Cortar / Colar:** Gerencie arquivos entre pastas; use comandos no menu ou atalhos.
- **Renomear:** Clique com o botão direito e escolha Renomear.
- **Excluir:** Use Excluir para remover; confirmações são solicitadas para exclusões em massa.
- **Restaurar / Desfazer:** Quando disponível, recupere exclusões recentes pela opção de restauração temporária.
- **Propriedades:** Veja informações completas do arquivo e histórico do evento.

## Pesquisa e Filtros
- **Pesquisa simples:** Digite termos na caixa de busca para localizar itens por nome.
- **Filtros pré-definidos:** Selecione filtros por tipo (imagens, vídeos, documentos), tamanho, data ou evento.
- **Combinar filtros:** Aplique múltiplos filtros simultaneamente para refinar os resultados.

## Salvando e Restaurando a Visualização
- **Salvar estado da tabela:** Guarda a disposição atual (ordem/largura/visibilidade de colunas) como um perfil.
- **Restaurar estado salvo:** Restaura o layout e filtros previamente salvos.

## Processamento em Lote e Extração de Metadados
- **Iniciar extração em lote:** Selecione vários itens e escolha "Extrair Metadados em Lote" para processar todos de uma vez.
- **Monitorar progresso:** Acompanhe o andamento pela barra de progresso e pelas mensagens do painel.
- **Cancelar/Pausar:** É possível pausar ou cancelar operações em lote; use os botões de controle enquanto o processo estiver ativo.

## Relatórios e Estatísticas
- **Gerar gráficos:** Acesse a seção de estatísticas para ver distribuições por tipo, uso de disco, eventos por data, entre outros.
- **Interpretando gráficos:** Cada gráfico terá legendas indicando categorias e percentuais; passe o mouse sobre as áreas para ver detalhes.
- **Exportar relatórios:** Exporte imagens dos gráficos ou dados (CSV) para análise externa.

## Monitoramento de Eventos (Notificações)
- **Tipos de eventos:** Criação, modificação, remoção, movimentação.
- **Visualização em tempo real:** Eventos recentes aparecem destacados; selecione para ver detalhes.
- **Configurar notificações:** Ajuste nas Preferências se deseja alertas visuais ou sonoros.

## Preferências e Configurações
Nas Preferências (Configurações) você pode ajustar:
- **Idioma da interface** — altere entre os idiomas suportados.
- **Comportamento de scan** — periodicidade, profundidade e exclusões.
- **Notificações** — ativar/desativar alertas.
- **Atualizações** — definir verificação automática ou manual.

## Problemas Comuns e Soluções (Rápidas)
- **Scan fica preso/levanta erro:** Aguarde alguns minutos; se persistir, tente reiniciar o scan ou reiniciar o aplicativo.
- **Itens não aparecem:** Verifique se a pasta correta está adicionada e se o aplicativo tem permissão de leitura.
- **Falha ao abrir arquivo:** Verifique se há um aplicativo associado ao tipo de arquivo no sistema.
- **Metadados ausentes:** Nem todos os arquivos contêm metadados; tente usar "Atualizar metadados" ou processar em lote.

## Perguntas Frequentes (FAQ)
- **Posso monitorar várias pastas?** Sim — adicione quantas pastas desejar à lista de monitoramento.
- **As alterações são permanentes?** A aplicação apenas lê e gerencia arquivos do sistema; exclusões feitas pelo aplicativo afetam o sistema de arquivos.
- **Como recuperar um arquivo excluído?** Use a opção de restauração temporária se disponível e se a exclusão tiver sido realizada recentemente.

## Atalhos Úteis (Resumo)
- **Ctrl+C / Ctrl+V:** Copiar / Colar
- **Del:** Excluir selecionado
- **F3 / Ctrl+F:** Foco na busca
- **Ctrl+S:** Salvar estado da tabela (se aplicável)

## Boas Práticas
- Faça um scan inicial em uma pasta pequena para familiarizar-se com o fluxo.
- Salve configurações e estados antes de operações em larga escala.
- Use filtros para trabalhar apenas com os itens relevantes.

## Ajuda e Contato
Consulte a seção **Ajuda** dentro do aplicativo para acessar este manual a qualquer momento. Para suporte adicional, verifique a seção **Sobre** para informações de contato e licenciamento.

## Novos Recursos e Funcionalidades Criadas no Projeto

Esta seção complementa o manual com os recursos mais recentes do projeto e mostra, em passos práticos, como usar cada melhoria no dia a dia.

## 1) Monitoramento em tempo real com detecção mais precisa
- **O que foi aprimorado:** captura mais confiável de criação, modificação, exclusão, renomeação e movimentação, com menor chance de registros repetidos em sequência.

**Como usar (passo a passo):**
1. Clique em **Adicionar Diretório** e selecione a pasta desejada.
2. Execute **Iniciar** ou **Scan** para montar a base inicial da pasta.
3. Ative o **monitoramento contínuo**.
4. Faça um teste simples com um arquivo de teste: crie, renomeie, mova e exclua.
5. Confirme na tabela se os eventos aparecem em sequência lógica.
6. Use filtros por tipo de evento para validar cada operação separadamente.

## 2) Controles de pausa, retomada e encerramento mais confiáveis
- **O que foi aprimorado:** fluxo de pausa/retomada/parada mais estável, com atualização de status mais clara durante operações longas.

**Como usar (passo a passo):**
1. Inicie um scan ou processamento em lote.
2. Quando desejar revisar o estado atual, use **Pausar**.
3. Verifique a tabela, mensagens e progresso antes de continuar.
4. Clique em **Retomar** para prosseguir exatamente do ponto operacional atual.
5. Para finalizar com segurança, use **Parar/Cancelar** e aguarde a atualização final do status.

## 3) Tabela principal mais estável em cenários com muitos eventos
- **O que foi aprimorado:** atualização visual mais ágil e consistente em listas grandes, mantendo melhor ordenação e leitura de dados.

**Como usar (passo a passo):**
1. Após iniciar o monitoramento, gere volume de eventos (ou monitore uma pasta com alta atividade).
2. Ordene por **Data** ou **Evento** para priorizar alterações recentes.
3. Aplique filtros por tipo de operação para reduzir ruído visual.
4. Abra os detalhes de linhas específicas para confirmar metadados sem perder o contexto.
5. Se necessário, pause o fluxo, revise os resultados e retome o monitoramento.

## 4) Troca de idioma mais consistente em toda a interface
- **O que foi aprimorado:** menus, tabela, manual, ajuda e estatísticas com comportamento de tradução mais uniforme.

**Como usar (passo a passo):**
1. Acesse as **Preferências** e abra a opção de **Idioma**.
2. Selecione o idioma desejado.
3. Confirme a alteração.
4. Verifique menu principal, títulos de colunas, seções de ajuda/manual e área de estatísticas.
5. Caso esteja em atividade intensa, prefira pausar operações antes da troca para facilitar validação visual.

## 5) Melhorias no gráfico "Fluxo de Tipo de Arquivo por Diretório"
- **O que foi aprimorado:** leitura visual mais limpa, agrupamento de caminhos repetidos e foco automático em itens mais relevantes para evitar poluição visual.

**Como usar (passo a passo):**
1. Acesse a seção de **Relatórios e Estatísticas**.
2. Selecione o gráfico de **Fluxo de Tipo de Arquivo por Diretório**.
3. Aplique filtros de período ou tipo de arquivo antes de gerar.
4. Analise os fluxos principais para identificar concentração de tipos por diretório.
5. Use rolagem e ajuste de visualização quando houver muitas legendas.
6. Exporte o gráfico se precisar compartilhar a análise.

## 6) Melhor comportamento de foco entre janelas auxiliares
- **O que foi aprimorado:** janelas de apoio (como ajuda/manual/sobre e diálogos auxiliares) com navegação mais previsível ao alternar foco com a janela principal.

**Como usar (passo a passo):**
1. Com o sistema em uso, abra uma janela auxiliar (ex.: ajuda/manual).
2. Retorne para a janela principal para continuar o monitoramento.
3. Alterne novamente para a janela auxiliar e confirme que a troca de foco está estável.
4. Feche janelas auxiliares após uso para manter o fluxo de trabalho organizado.

## 7) Fluxo recomendado para usar os novos recursos em conjunto
1. Adicione diretórios e execute o scan inicial.
2. Ative monitoramento contínuo.
3. Em caso de pico de eventos, ordene e filtre a tabela para foco rápido.
4. Use pausa estratégica para revisar pontos críticos sem perder controle da sessão.
5. Retome e continue a captura normalmente.
6. Gere estatísticas e analise o fluxo por diretório/tipo.
7. Exporte relatórios para auditoria e histórico.
8. Ajuste idioma e preferências quando necessário.
9. Encerre operações longas com parada controlada e confirmação de status final.

## 8) Popup de segurança configurável (limite, linhas e intervalo)
- **O que foi aprimorado:** o alerta de segurança agora permite configuração de limite mínimo para disparo, quantidade máxima de linhas por alerta e intervalo entre exibições consecutivas.

**Como usar (passo a passo):**
1. Abra o menu de **Segurança** e entre na configuração de popup/notificações.
2. Defina o **limite mínimo** para disparo do alerta.
3. Ajuste o **máximo de linhas** exibidas por popup para evitar excesso visual.
4. Configure o **intervalo (cooldown)** entre alertas.
5. Salve e faça um teste com eventos reais para validar frequência e legibilidade.

## 9) Classificação de eventos: Renomeado x Movido
- **O que foi aprimorado:** o sistema diferencia melhor eventos de renomeação e movimentação para auditorias mais claras.

**Como interpretar:**
1. **Renomeado:** quando o item permanece na mesma pasta e muda somente o nome.
2. **Movido:** quando o item muda de diretório, com ou sem mudança de nome.
3. Para revisão, filtre por coluna **Evento** e confira os caminhos no painel de detalhes.

## 10) Estatísticas com sincronização de dados pendentes
- **O que foi aprimorado:** abertura de estatísticas com maior consistência quando há gravações recentes em andamento.

**Como usar (passo a passo):**
1. Antes de abrir estatísticas, aguarde concluir operações pesadas ou use **Pausar**.
2. Abra a janela de estatísticas e confirme ausência de pendências no status.
3. Se identificar divergência pontual, feche a janela, aguarde estabilização e abra novamente.

## 11) Modo gráfico avançado para compatibilidade (OpenGL)
- **O que foi aprimorado:** suporte a modo de inicialização gráfica configurável para cenários de compatibilidade.

**Como usar:**
1. Antes de abrir o aplicativo, configure a variável de ambiente **LINCEU_OPENGL_MODE**.
2. Valores aceitos: **auto**, **desktop**, **angle**, **software**.
3. Use **software** apenas para diagnóstico de compatibilidade (pode reduzir desempenho).

## Complemento operacional dos novos menus e recursos

Esta seção explica como utilizar, em fluxo real de trabalho, os recursos adicionados nos menus **Arquivo**, **Configurações** e **Segurança**.

## 12) Menu Configurações > Estatísticas > Plotar Gráficos

O submenu **Configurações > Estatísticas > Plotar Gráficos** define quais gráficos serão gerados quando você abrir a janela de estatísticas. Ele não é apenas uma descrição visual: as opções marcadas são salvas e reutilizadas depois.

**Como usar:**
1. Abra **Configurações > Estatísticas > Plotar Gráficos**.
2. Marque apenas os gráficos que deseja gerar.
3. Desmarque gráficos que não são úteis para a análise atual, especialmente em bases grandes.
4. Abra **Arquivo > Estatísticas** ou pressione **Ctrl+G**.
5. A janela de estatísticas será criada usando a seleção configurada.

**Onde a preferência fica salva:**
- A seleção é persistida no arquivo `statistics_charts_config.json`, dentro do diretório de dados persistentes da aplicação.

**Gráficos novos e quando usar:**
- **Fluxo de Operações em Arquivos:** use para entender como os eventos se distribuem entre criação, modificação, exclusão, movimentação e renomeação.
- **Fluxo de Evento por Diretório:** use para descobrir quais pastas concentram tipos específicos de eventos.
- **Fluxo de Tipo de Arquivo por Diretório:** use para identificar quais extensões ou categorias aparecem em cada caminho monitorado.
- **Árvore de Diretórios:** use para navegar visualmente pela concentração de eventos por nível de pasta.
- **Heatmap, Scatter, Radar e Dotplot:** use para comparar concentração temporal, tamanhos de arquivo e distribuição das operações.

## 13) Janela de Estatísticas

Depois de abrir **Arquivo > Estatísticas** ou **Ctrl+G**, use a janela de estatísticas assim:

1. No painel **Selecionar gráficos**, marque ou desmarque os gráficos que quer manter visíveis naquela sessão.
2. Use **Selecionar todos** para reativar todos os gráficos disponíveis.
3. Use **Atualizar** depois de novos eventos, após troca de idioma ou depois de mudar a seleção de gráficos.
4. Use **Salvar selecionados** para exportar apenas os gráficos marcados em arquivos PNG.
5. Use **Salvar todos** para exportar todos os gráficos gerados para uma pasta com data e hora no nome.
6. Oculte o painel de seleção quando precisar de mais espaço para inspecionar as abas.

**Boas práticas:**
- Execute um scan inicial antes de abrir estatísticas.
- Em pastas com muitos eventos, aguarde o status estabilizar antes de gerar gráficos.
- Se os números parecerem incompletos durante uma escrita recente, clique **Atualizar** ou feche e abra a janela novamente.

## 14) Menu Configurações > Segurança

O submenu **Configurações > Segurança** concentra recursos de auditoria, evidência, alertas e recuperação.

### Perfis e multi-diretório

Use **Configurações > Segurança > Perfis e multi-diretório** para operar com vários diretórios no mesmo perfil.

1. Abra a janela de perfis.
2. Clique **Adicionar diretório** para incluir uma nova pasta monitorada.
3. Selecione uma pasta na lista e clique **Remover selecionado** para removê-la do perfil.
4. Altere **Nome do perfil** para identificar melhor o conjunto monitorado.
5. Clique **Salvar perfil**.
6. Use **Atualizar** para recarregar o resumo de diretório principal, total de diretórios e perfil ativo.

### Central de alertas

Use **Configurações > Segurança > Central de alertas** para priorizar ocorrências por risco.

1. Abra a central.
2. Revise as colunas **Criado em**, **Nível de risco**, **Resumo do alerta**, **Regras**, **Caminho**, **Nome**, **Sessão** e **Evidência**.
3. Comece por alertas altos ou críticos.
4. Use **Atualizar** enquanto o monitoramento estiver ativo para carregar registros novos.

### Sessões em tempo real

Use **Configurações > Segurança > Sessões em tempo real** para acompanhar blocos de atividade.

1. Abra a janela de sessões.
2. Verifique a sessão, total de eventos e diretórios envolvidos.
3. Use essas informações para relacionar picos de atividade com diretórios monitorados.
4. Clique **Atualizar** quando quiser carregar novas sessões sem fechar a janela.

### Quarentena e restauração

Use **Configurações > Segurança > Quarentena e restauração** para revisar itens isolados e versões monitoradas.

1. Abra a janela.
2. Na aba **Quarentena**, selecione uma linha.
3. Use **Abrir pasta selecionada** para localizar a cópia isolada.
4. Use **Restaurar cópia selecionada** somente depois de validar o destino.
5. Na aba **Versões monitoradas**, selecione uma linha e use **Restaurar versão monitorada** para recuperar uma versão acompanhada.
6. Prefira restaurar para uma pasta de revisão antes de substituir arquivos em uso.

### Pacote de evidência

Use **Configurações > Segurança > Pacote de evidência** para gerar um pacote auditável.

1. Abra a janela.
2. Clique **Selecionar destino** e escolha a pasta onde o pacote será criado.
3. Clique **Exportar agora**.
4. Após a geração, clique **Abrir pasta selecionada** para conferir os arquivos exportados.
5. Guarde o pacote antes de limpar histórico ou encerrar uma análise crítica.

### Limpar banco de segurança

Use **Limpar banco de segurança** com cautela.

- Exporte evidências antes de limpar.
- Confirme que o histórico antigo não será mais necessário.
- Evite limpar durante monitoramento ativo ou antes de concluir uma auditoria.

## 15) Notificações de segurança

As notificações podem aparecer no rodapé/barra de status ou como pop-ups separados.

**Como configurar:**
1. Abra **Configurações > Segurança > Notificações**.
2. Ative **Alertas de segurança** para exibir resumos no rodapé/barra de status.
3. Abra **Pop-ups de alertas**, **Pop-ups de sessões** ou **Pop-ups de quarentena** para configurar cada tipo.

**Campos da configuração:**
- **Ativar este pop-up:** liga ou desliga aquele tipo de janela.
- **Disparar ao atingir:** define o número mínimo de eventos/linhas acumuladas antes do aviso.
- **Máximo de linhas no resumo:** limita o tamanho do conteúdo exibido.
- **Cooldown entre pop-ups:** define o intervalo mínimo entre avisos. Use `0` apenas quando quiser ver todos os picos imediatamente.

**Fluxo recomendado:**
1. Comece com um limite baixo em uma pasta de teste.
2. Gere alguns eventos reais.
3. Aumente o limite se os avisos aparecerem com frequência excessiva.
4. Reduza o máximo de linhas se o pop-up ficar grande demais.
5. Aumente o cooldown para evitar interrupções durante picos de eventos.

## 16) Opções de exportação

Antes de salvar dados, configure **Configurações > Opções de exportação**.

- **Exportar colunas ativas:** exporta apenas colunas visíveis/ativas na tabela.
- **Exportar filtros ativos:** exporta apenas os dados que passam pelos filtros atuais.
- **Exportar seleção:** exporta somente as linhas selecionadas.
- **Resetar opções de exportação:** volta ao comportamento padrão.

**Como usar em auditoria:**
1. Aplique filtros por evento, diretório ou tipo.
2. Ajuste as colunas visíveis.
3. Marque as opções de exportação adequadas.
4. Use **Arquivo > Salvar como** para escolher formato como CSV, TXT, JSON, XML, SQLite, XLSX ou pacote de evidência, conforme disponível.

## 17) Fluxo recomendado usando os novos recursos juntos

1. Abra o aplicativo.
2. Use **Arquivo > Selecionar Diretório** ou **Configurações > Segurança > Perfis e multi-diretório** para montar o conjunto monitorado.
3. Execute o scan inicial.
4. Ative o monitoramento contínuo.
5. Configure filtros, colunas e opções de exportação.
6. Configure **Configurações > Estatísticas > Plotar Gráficos** para gerar apenas gráficos relevantes.
7. Abra **Arquivo > Estatísticas** ou **Ctrl+G**.
8. Exporte gráficos com **Salvar selecionados** ou **Salvar todos**.
9. Revise **Central de alertas** e **Sessões em tempo real**.
10. Se houver itens isolados, revise **Quarentena e restauração**.
11. Gere um **Pacote de evidência** antes de encerrar a auditoria.
